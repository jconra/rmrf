Foam band

0 = today's behaviour: band measured in HEIGHT, so a flat shore spreads it enormously. 1 = the same width on the ground whatever the slope.
Height above the waterline where surf is fully gone. Slope-normalising trades height for ground distance, so on a steep beach it can wash right up onto the grass — this is the ceiling that stops it. The sand band ends at 1.0.
Surf needs open water to build, so the outer coast should break hardest and sheltered inland seas should barely foam. 0 = the same everywhere.

Wave roll-in

How far out of step stretches of coast are. Below ~6.3 (one full cycle) the whole shoreline still breaks together — push past that to stagger them.
How quickly that stagger changes as you walk the shore. Small = long lazy stretches in step; large = neighbouring bays break at different moments.

Crest shape

Narrow gap = a hard bright line of white water. Wide = a soft wash.

GPU cost

fps sits at 60 whatever you change, because the frame waits for vsync and render() only QUEUES work. Measure mode draws the scene several times and then blocks on gl.finish(), so the reading is real GPU time per draw.
More draws = a bigger, steadier signal. Raise it until the ms reading stops jumping around.
The chop is FILL-RATE work, so it costs per water pixel. Push this up to see what a denser display (or a phone at native resolution) would feel.
